# 찐리뷰 노트

리뷰를 모으고 판정하는 개인용 도구입니다. 휴대폰과 노트북 어디서나 같은 데이터로 작업합니다.

- 바로 열기: https://claude.ai/artifact/1sgXvUKEDbnYUFbt6qSP8a
- 원본 파일: `app/review-lab.html` 하나로 되어 있습니다.

## 쓰는 흐름

1. **수집 (노트북 권장)**
   - 상품을 등록합니다. 상품명, 판매 채널, 카테고리, 원문 링크를 적습니다.
   - 상품 페이지의 리뷰 영역을 복사해 붙여넣고 **리뷰로 나누기**를 누릅니다.
   - claude.ai에서 열면 AI가 리뷰를 나누고, 그 밖에서는 날짜 줄을 기준으로 나눕니다.
   - 별점, 날짜, 체험단 같은 표시를 확인하고 **풀에 추가**합니다. 닉네임과 사진은 저장하지 않습니다.
2. **판정 (휴대폰 권장)**
   - 판정 화면을 열면 리뷰가 한 장씩 나옵니다.
   - 실사용 증거(0~3)와 홍보·의심 신호(없음·약함·강함)를 누르고, 이유 칩을 고른 뒤 **저장하고 다음**을 누릅니다.
   - 노트북에서는 키보드로도 됩니다. 0~3은 실사용, Q·W·E는 의심, Enter는 저장, S는 건너뛰기, Z는 되돌리기입니다.
3. **현황**
   - 판정 분포, 나와 나의 일치도, 별점×길이 칸별 판정 수, 길이 편향, 이유 칩 사용, 상품별 요약을 봅니다.
4. **설정**
   - 주간 목표, 재판정 비율과 간격, 평가용 분리 비율, 이유 칩 목록을 바꿉니다.
   - 엑셀용 CSV와 전체 백업 JSON을 내려받고, 백업을 다시 가져옵니다.

## 선검토 수정사항 반영

| 선검토의 수정사항 | 앱에서의 반영 |
|---|---|
| 수집과 판정 분리 | 수집 화면에서 풀을 채우고, 판정 화면은 풀에서 한 장씩 꺼냄 |
| 수동 붙여넣기 + AI 정규화 | 붙여넣은 텍스트를 AI 또는 규칙으로 별점·날짜·옵션·표시·도움돼요·본문으로 나눔 |
| 라벨 두 축 분리 | 실사용 증거 0~3, 홍보·의심 없음·약함·강함 |
| 찐/애매/가짜 → 파생 태그, "가짜" → "의심" | 두 축에서 찐·애매·의심을 자동 계산 |
| 이유 입력을 체크칩으로 | 실사용 근거 칩 7개, 의심 근거 칩 5개, 설정에서 수정 가능 |
| 10% 재판정 | 판정 후 14일이 지난 리뷰를 10% 확률로 가려서 다시 물음 |
| 자기 일치도 측정 | 재판정 10개 이상이면 코헨 카파와 축별 일치율 표시 |
| 경계 사례 확보 | 별점×길이 칸 중 판정이 적은 칸부터 먼저 보여 줌 |
| 길이 편향 점검 | 길이 구간별 태그 분포와 경고 |
| 평가용 20% 분리 | 첫 판정 때 20% 확률로 평가용 표시, 나중에 AI 평가에 사용 |
| 주간 목표 관리 | 이번 주 판정 수와 목표 진행 막대 |
| 스키마 v2 필드 | 별점, 작성일, 구매 옵션, 플랫폼 표시, 도움돼요, 글자 수, 카테고리, 판정 일시, 재판정, 수집 방식 |
| 개인정보 최소 저장 | 닉네임·사진은 저장하지 않고 원문 링크와 본문만 저장 |

## 판정 규칙

| 파생 태그 | 조건 |
|---|---|
| 찐 | 실사용 증거 2 이상이고 의심 신호 없음 |
| 의심 | 의심 신호 강함, 또는 의심 신호 약함이면서 실사용 증거 1 이하 |
| 애매 | 그 밖의 모든 경우 |

"의심"은 개인 판단 기록입니다. 리뷰가 가짜라고 확정하는 뜻이 아니므로 외부에 공개하지 않습니다.

## 데이터 저장

- claude.ai에서 열면 Claude 저장소에 저장되고 기기 간에 동기화됩니다. 기본 공개 범위는 본인만입니다.
- 저장소 한도는 문서 5,000개입니다. 리뷰 1개가 문서 1개이므로 1단계 목표인 300~1,000개에는 충분합니다.
- 파일을 브라우저로 직접 열면 그 브라우저에만 저장됩니다. 이때는 백업 JSON을 자주 받아 두세요.

| 저장 위치 | 내용 |
|---|---|
| `products/<id>` | 상품명, 판매 채널, 카테고리, 원문 링크 |
| `reviews/<id>` | 리뷰 필드, 첫 판정(`label`), 재판정(`rejudge`) |
| `meta/settings` | 주간 목표, 재판정·평가용 비율, 이유 칩 목록 |

## 아직 없는 것

- 2~3단계의 AI 판정은 라벨이 150개 이상 모인 뒤 붙입니다.
- 4단계의 페이퍼 트레이딩 추적과 상품 동일성 매칭은 아직 없습니다.
